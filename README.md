# AI/ML Engineering Internship – DevelopersHub Corporation

## Task 1: Iris Dataset EDA

| Requirement | Details |
|-------------|---------|
| **Objective** | Load, inspect, and visualize the Iris dataset to understand data trends |
| **Dataset** | Iris dataset (150 samples, 4 features, 3 species) |
| **Tools/Models** | pandas, matplotlib, seaborn (visualization only, no ML model) |
| **Key Results** | Scatter plots showed species separation; histograms showed feature distributions; box plots identified no major outliers |

## Task 3: Heart Disease Prediction

| Requirement | Details |
|-------------|---------|
| **Objective** | Predict whether a person is at risk of heart disease based on health data |
| **Dataset** | Heart Disease UCI (303 samples, 14 features) |
| **Models Applied** | Logistic Regression, Decision Tree |
| **Key Results** | Logistic Regression achieved 88.3% accuracy; Decision Tree achieved 76.7% accuracy. Top features: chest pain type, thalassemia, major vessels |

---

## Task 4: Health Query Chatbot

| Requirement | Details |
|-------------|---------|
| **Objective** | Create a chatbot that answers general health-related questions using an LLM |
| **Dataset/Tool** | Hugging Face Transformers (DistilGPT2 model) |
| **Models Applied** | Text generation with prompt engineering |
| **Key Results** | Successfully answered: "What causes a sore throat?", "Is paracetamol safe for children?", "How to reduce fever?" with safety disclaimers |
